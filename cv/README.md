# cv

**履歴書・申請書に転記するための業績データを置く場所です。**

researchmap を正本とし、そこからエクスポートしたものを履歴書の様式に合わせて並べ替えた
マスターをここに持ちます。非常勤講師の応募、科研費の申請、学内書類などで、同じ内容を
様式ごとに書き直す手間をなくすためのものです。

[bibliography/](../bibliography/) と対になります。あちらが業績の「中身」（Zotero が正本）、
こちらが業績の「一覧」（researchmap が正本）です。どちらも**外部システムが正本で、
ここにあるのは転記用の派生データ**です。

## 構成

| 場所 | 中身 |
|---|---|
| `master/` | 履歴書記入用のマスターCSV。`★` を埋めて使う |
| `pending/` | researchmap にまだ登録していない追加分の置き場 |

## 使い方

1. researchmap の「業績一覧ダウンロード」でエクスポートし、`rm_*.csv` としてこの直下に置く
2. `master/` の各ファイルに転記する（`★` が入力すべきセル）
3. 履歴書の様式に合わせて `master/` から書き写す

`master/` の9ファイルは、大学の非常勤講師用履歴書によくある項目立てに対応させてあります。
様式が違っても、同じマスターから転記できます。**UTF-8 BOM付きなので Excel でそのまま開けます。**

| ファイル | 対応する欄 |
|---|---|
| `01_基本情報.csv` | 氏名・生年月日・国籍・連絡先 |
| `02_学歴.csv` | 学歴 |
| `03_学位.csv` | 学位 |
| `04_職歴.csv` | 職歴（常勤・非常勤を一本化） |
| `05_所属学会.csv` | 所属学会 |
| `06_専門分野.csv` | 専門分野 |
| `07_学術論文.csv` | 学術論文 |
| `08_著書・翻訳.csv` | 著書・翻訳 |
| `09_講演・口頭発表.csv` | 学会における講演、口頭発表 |
| `10_その他（掲載欄の判断用）.csv` | 様式外。書評・翻訳・連載をどの欄に載せるかの判断用 |

## 記入のルール

- **`★` が入力すべきセル。** 全ファイルを `★` で検索すれば残りの作業量が分かる
- **`メモ` 列は転記時の注意書き。** 履歴書には転記しない
- **提出日によって変わる項目は空欄のまま残す**（作成日・満年齢など）
- **継続中の職・学会は `至` に `～現在` と書く**
- 様式が学歴・学位・職歴に「日」列を求めることがある。学位記や辞令で確認する

## 基本情報の扱い（重要）

**`01_基本情報.csv` は `.gitignore` で除外してあります。** 生年月日・住所・電話番号を
入れる場所なので、既定では追跡しません。使うときは雛形をコピーしてください。

```bash
cp cv/master/01_基本情報.csv.example cv/master/01_基本情報.csv
```

現住所や自宅の電話番号は、**マスターに持たず提出のたびに直接入力する**運用をお勧めします。
本務先の住所・電話は変わらないのでマスターに持たせて構いません。

このリポジトリを private で使っていても、**公開リポジトリへ転記・コピーしないよう注意してください。**

## 複数のリポジトリを持つようになったら

CV は**研究目的ではなく研究者本人に属する**ものです。このリポジトリを終了しても、
別のテーマで新しいリポジトリを作っても、CV は付いて回ります。

そのため、研究リポジトリを複数持つようになったら、**`cv/` はこのリポジトリの外に出してください。**
個人用のリポジトリを1つ作るか、`repos/` に独立したリポジトリとして置くのが自然です。

ここに置いているのは、最初のうち1つのフォルダで完結させるためです。
