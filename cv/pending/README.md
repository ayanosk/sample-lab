**researchmap のインポート書式のまま書いておく**と、2つの役目を兼ねられます。

1. researchmap の「研究者・業績インポート」にそのままアップロードできる
2. researchmap に入れる前でも、`../master/` に転記して履歴書に使える

## 書き方

エクスポート原本（`../rm_<table>*.csv`）の1行目（テーブル名）と2行目（ヘッダ）をそのまま写し、
3行目以降にデータを書きます。

- 未設定は空欄ではなく `null`
- BOM は付けない（エクスポート原本と違う点です）
- `アクション名` は `insert`、`アクションタイプ` は `merge`、`ID` は空

researchmap に登録して次回エクスポートに反映されたら、ここからは消してください。
