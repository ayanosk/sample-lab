# work

**このリポジトリの目的に従属する作業のまとまりを置く場所です。** ここの中身はすべて、このリポジトリと同じ履歴・同じ公開範囲で扱われます。

```text
work/
  project_a/          ← 作業単位。名前は自分の用途に変える
    sources/          元データ。上書きしない
    scripts/          処理用のコード
    outputs/          生成物
    docs/             メモ・下書き・作業ログ
  project_b/
  publications/       ← 原稿の制作。完成版は publications/ へ出す
    conference-a/
```

## 粒度は自由

`data-cleaning/` `conference-paper/` のように作業ごとに細かく分けても、`project_a/` のようにテーマごとに大きく持ってもかまいません。大事なのは大きさではなく次の点です。

- このリポジトリの目的に従属している
- このリポジトリと同じ履歴・公開範囲でよい
- 元データと生成物が区別できる

## 別リポジトリに分けるとき

次のようになったら `repos/` の独立リポジトリへ移します（[repos/README.md](../repos/README.md)）。

- 別の共同編集者が現れた
- 単独で配布・引用・バージョン付けしたくなった
- 別のライセンスが必要になった
- このリポジトリを終了した後も保守を続ける

逆に、**関係のない研究テーマをここに並べないでください。** 履歴・公開範囲・エージェントへの文脈が混ざります。その場合はテンプレートから別のリポジトリを作ります。
