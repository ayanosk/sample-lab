# project_a

作業単位の最小構成サンプルです。**名前は自分の用途に合わせて変えてください**（`analysis/`、`fieldwork/` など）。

## フォルダの役割

- `sources/` : 元データ。**上書きせず**、必要なら複製して使う。置けるのは**著作権上問題のないもの**だけで、購入した PDF や利用に制限のある史資料は工房の外に置く
- `scripts/` : 処理用コード。同じ処理を繰り返すならここに残す
- `generated/` : `scripts/` を動かせば作り直せるもの。`.gitignore` で追跡から外してある
- `drafts/` : 人に出すものの制作。発表・論文ごとにフォルダを作る（図もその中に置く）
- `docs/` : メモ、下書き、作業ログ、判断理由

## このフォルダだけのルールが要るとき

`work/project_a/AGENTS.md` を作り、**親の [AGENTS.md](../../AGENTS.md) と違う点だけ**を書きます。
同じ内容を書き写すと、片方を直したときにもう片方がずれます。
