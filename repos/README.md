# repos

**別のGitリポジトリが必要になったものを置く場所です。** ここの中身はこのリポジトリでは追跡しません（`.gitignore` で除外済み）。

## ここに置くもの

次のどれかが当てはまるなら、`work/` ではなくここに独立したリポジトリとして置きます。

- 別の共同研究者と共有する（read/write 権限を分けたい）
- 公開する、または公開の時期・範囲がこのリポジトリと違う
- 別のライセンスや保存期間を適用する
- 単独で引用・バージョン付けしたい（データセット、ソフトウェアなど）
- このリポジトリを終了・凍結した後も保守を続ける

```bash
cd repos
git clone <リポジトリのURL>
```

## ここに置かないもの

**「大きいから」「重要だから」という理由では分けません。** 履歴・権限・公開範囲を分ける必要がないなら `work/` のままにしてください。ディレクトリを分けてもGitの境界は変わりません。

## 注意

`repos/` は追跡されないので、**このリポジトリを clone しただけでは復元できません。** 何をどこから取得するかは、各リポジトリのURLを控えておいてください。

Git は版管理であってバックアップではありません。追跡していないファイルは、clone からは戻りません。
